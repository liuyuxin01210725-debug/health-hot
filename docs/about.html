METHODOLOGY · 方法论

我们怎么把「听来的」
变成「有据的」

这个库不生产观点，它核验说法。每一条结论怎么来、证据强弱怎么分、什么时候复核、发现错了怎么改——都写在这里。

01

三类依据：先看「凭什么相信」

每条说法先归入三类之一。研究支持：可点回 PubMed / DOI / Cochrane 等研究锚点。官方依据：可点回 WHO、NIH、卫健委、中国疾控等白名单机构的具体页面。前沿待核：来自专家、播客或趋势线索，但核验依据还没补齐。三类不互相冒充：官方建议不是原始研究，前沿观点也不是结论。

02

证据分级：再标「依据有多硬」

在依据状态之外，再按证据强度分七级。两个维度组合出可信度光谱：一条可以是「研究支持 + Meta」，也可以是「官方依据 + 指南」或「前沿待核 + 专家」。

03

双链接：你在哪听到 ≠ 凭什么相信

发现来源（discovery）是「你可能在某播客听到这个说法」，核验依据（evidence）是「研究或官方原文在哪里」。播客负责提出问题，研究与官方页面负责提供可回溯依据。

04

信源体系：三种角色，各司其职

锚点 ANCHOR
决定结论、做核验依据WHO / USPSTF / NIH 官方事实页与指南，PubMed 的 Cochrane 系统综述 / 指南 / 系统综述查询
发现 DISCOVERY
只负责发现「大家在讨论什么」，不下结论可信专家的播客 / YouTube / 博客进入候选池，但不能自动作为核验依据
雷达 RADAR
追踪新论文与趋势PubMed 窄主题查询；趋势不能直接冒充结论
05

复核与纠错

每条都带复核日期，随研究更新而重新审视。发布前有自动闸门：缺来源、未来日期、伪链接、未审核的条目一律进不了线上。发现错误？欢迎通过 GitHub issue 指出。

06

内容红线

这是健康产品，有刚性约束：不是医疗建议，不开处方、不给具体剂量、不暗示治疗任何疾病；不确定的、证据弱的，明确标注，绝不替它下定论。

07

谁做的、靠什么活（利益披露）

这个库由个人维护，没有任何商业收入：不卖任何产品、不接补剂或品牌广告、不做带货、不收会员费，页面上也不会出现联盟链接。做它的唯一目的，是把自己查过的健康/健身/补剂说法公开出来，让别人少交点智商税。正因为不靠卖东西赚钱，这个库才敢在结论里直说「这个没用」「这个被夸大了」——没有任何产品需要我替它说好话。
