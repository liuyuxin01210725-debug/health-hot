METHODOLOGY · 方法论

我们怎么把「听来的」
变成「有据的」

这个库不生产观点，它核验说法。每一条结论怎么来、证据强弱怎么分、什么时候复核、发现错了怎么改——都写在这里。

01

两层信任：先分「查实了没有」

每条说法先归入两种状态之一。已核验：有独立的 PubMed / 官方指南 / Cochrane 研究支撑，可点回原始研究。专家梳理·证据待补：来自播客或专家的梳理，方向有参考价值，但原始研究链接还没补齐。我们老实标注「还没查到」，这不是错误，是诚实。

02

证据分级：再标「支撑它的研究有多硬」

对有研究支撑的条目，再按证据强度分七级。两个维度组合出可信度光谱：一条可以是「已核验 + Meta」，也可以是「专家梳理待补 + 专家」。

03

双链接：你在哪听到 ≠ 凭什么相信

发现来源（discovery）是「你可能在某播客听到这个说法」，核验依据（evidence）是「支撑它的研究在哪里」。播客负责提出问题，研究负责回答问题。

04

信源体系：三种角色，各司其职

锚点 ANCHOR
决定结论、做核验依据WHO / USPSTF / NIH 官方事实页与指南，PubMed 的 Cochrane 系统综述 / 指南 / 系统综述查询
发现 DISCOVERY
只负责发现「大家在讨论什么」，不下结论播客 / YouTube 等创作者入口默认不采集，需要时手动启用
雷达 RADAR
追踪新论文与趋势PubMed 窄主题查询；趋势不能直接冒充结论
05

复核与纠错

每条都带复核日期，随研究更新而重新审视。发布前有自动闸门：缺来源、未来日期、伪链接、未审核的条目一律进不了线上。发现错误？欢迎通过 GitHub issue 指出。

06

内容红线

这是健康产品，有刚性约束：不是医疗建议，不开处方、不给具体剂量、不暗示治疗任何疾病；不确定的、证据弱的，明确标注，绝不替它下定论。
