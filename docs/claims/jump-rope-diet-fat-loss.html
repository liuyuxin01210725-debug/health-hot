只跳绳、不改饮食，八周几乎不掉脂

一句话结论光跳绳不改饮食八周几乎不掉脂，配合少吃才真瘦。

证据强度
RCT 随机对照试验——证据强度高，但仍要看样本与重复性。
适用于谁
未特别限定，见原文
需要注意
结论基于单项八周三臂 RCT，样本与具体方案见原文核对；减脂以控制饮食为主，跳绳无特殊燃脂魔法。
详情
把人分成"只控饮食 / 只跳绳 / 又控又跳"三组，八周后——光跳绳不改饮食那组，体脂、血脂、胰岛素几乎没动；只有配合少吃才真瘦。你瘦不瘦主要看吃多少，跳绳没有"特殊燃脂魔法"。
