总觉得身体僵？几个在家能做的活动度自测

一句话结论把活动度当成可长期维持、不必随龄必然退化的能力。

详情
Kelly Starrett 给了几个在家能做的活动度自测：坐下-起立测试（sit-and-rise，有观察性研究与死亡率相关，但不是因果）、沙发拉伸测髋伸展、能不能舒服地坐地上。要点不是「达标」，而是把活动度当成可长期维持、不必随龄必然退化的能力。专家观点 + 实操，自测量力而行。
