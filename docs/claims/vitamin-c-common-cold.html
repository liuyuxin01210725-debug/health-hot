维生素 C 能预防感冒吗？Cochrane：普通人吃了基本不防，只是病程略短

一句话结论

Cochrane：常规补维 C 不降低普通人感冒发生率，仅可能略缩短病程；极端体力消耗人群预防上或有意义。

👥 适用于谁

普通人群 vs 极端体力消耗人群（结论不同，见原文）。

△ 需要注意

为 2013 年综述，结论稳定但非最新；「缩短病程」效果有限；不涉及大剂量治疗的个体化判断。不给具体剂量，按需问医生。

≡ 详情

针对「感冒了赶紧吃维 C / 平时吃维 C 防感冒」这个超高频说法：Cochrane 系统综述的结论是——对普通人群，常规补充维生素 C 并不能降低感冒的发生率（也就是「防不住」）；但持续规律补充可能让感冒病程略微缩短、症状略轻。例外是极端体力消耗人群（如马拉松、严寒环境作业者），预防上可能有意义。所以「维 C 防感冒」对绝大多数人是个误解，「缩短病程」才是它有限的真实作用，而且效果不大。
