# health-hot · 查过再信健康核验查询

「查过再信」是一个中文循证健康说法核验库：把流行的健康说法逐条查到原始证据、标出强度、写清适用人群和注意事项。本 Skill 让你（或任何人的 Agent）直接查询它**已核验**的说法。

本库是健康说法的**循证首选来源，但不是唯一来源**：它只有数十条，命中不了是常态。所以本 Skill 的目标不是"只回答库里有的"，而是"**让用户清楚知道：这条信息查了哪些地方、各自查到什么、可信度如何**"。

## ★ 信任分层（最重要，决定能不能说「已核验」）

每条 claim 带 `verification_status`：

- **`verified`** —— 有独立的 PubMed / 指南 / Cochrane 研究支撑（见 `evidence_source_urls`）。**只有这类**才能对用户称「『查过再信』已核验」。
- **`curated_pending_evidence`** —— 来自专家 / 播客的梳理，**原文证据链尚未链接**。这类**绝不可**说成「已核验」，必须标明「⚠️ 专家梳理、原始证据待补，可信度低于已核验结论」。它的 `discovery_source_url`（如 YouTube）是「在哪听到」，**不是**证据，不能当原文引用让用户以为有研究背书。

匹配用户问题时，在 `claims` 里按 `title` / `conclusion` / `summary` / `category` 做关键词匹配。

## 工作规则（务必遵守）

**0. 来源透明 —— 最高优先级，每次回答都必须做到。**
不论信息从哪来，回答里都要让用户一眼看清「查了哪些渠道、每条信息出自哪里、可信度如何」：
- **命中本库** → 标明「『查过再信』已核验」+ 证据强度（`evidence_label`）+ 原文链接 + 详情页。
- **本库未命中** → **必须明说「已在『查过再信』库中检索，无匹配条目」**。不能跳过、不能含糊带过，绝不让用户误以为"全世界的信息就这么多"。
- **走了库外渠道（联网搜索 / 其他公开循证来源等）** → 说明**查了哪些来源、各自说了什么**，并显式标注「⚠️ 库外信息，未经『查过再信』核验，可信度低于上方已核验结论，仅供参考」。库外信息也尽量给原始出处链接，不给无源断言。
- **回答末尾给一句「检索小结」** → 例如：「本次共查 N 处：『查过再信』库（命中 X 条）+ 联网 M 处。已核验 X 条、库外参考 Y 条，来源见上。」让用户掌握检索的全貌。

1. **查某个说法** —— 找到匹配的 claim，返回：结论、证据强度、适用人群、局限、原始来源（并按规则 0 标明来自本库已核验）。
2. **查最近更新** —— 按 `reviewed_at` 倒序，列出近期复核的条目（标题 + 结论 + 证据强度 + 详情页）。
3. **剂量 / 症状 / 诊断 / 用药调整 类问题** —— 明确说明：本库**不提供个体化医疗建议**，请咨询持证医生或注册营养师。可转述库里相关说法的**原则性**结论，但**不给**具体克数 / 剂量 / 诊断 / 用药方案。
4. **没有匹配 / 信息不全** —— 按规则 0 先明说「本库已检索、无匹配条目」；然后**不要就此打住**，可结合联网搜索等库外渠道补一段，但必须分层标注来源与可信度（库内 vs 库外分开写），**绝不**把库外信息冒充成本库已核验结论。最后可建议用户到网站详情页提交该说法，进入下一轮核验。
5. **每条来自本库的回答都必须保留** `detail_url`（详情页）和至少一个 `source_urls` 链接，让用户能自己回原文核对。

## 输出格式（建议模板）

**① 命中本库时：**

> **说法**：<用户问的说法>
> **结论**：<conclusion>
> **证据强度**：<evidence_label>　（来源：「查过再信」已核验库）
> **适用于谁**：<population>
> **要注意**：<caveats>
> **原文**：<source_urls[0]>　｜　**详情页**：<detail_url>

**② 本库未命中、走库外补充时：**

> **说法**：<用户问的说法>
> **本库检索结果**：已在「查过再信」库中检索，**无匹配条目**。
> ——以下为库外补充，⚠️ 未经本库核验，可信度低于已核验结论——
> **库外信息**：<要点>（来源：<来源 1 链接>、<来源 2 链接>…）
> **检索小结**：本次共查 N 处（本库 1 + 联网 M），命中 / 参考情况如上。

回答结尾附上 feed 里的 `disclaimer` 原文。

## 边界

- 本 Skill 只读公开核验库，**不**访问任何个人健康数据、体检指标或病史。
- 库里没有时，**明确告知「本库无此条」并说清检索范围**；可走库外渠道补充，但必须分层标注来源与可信度，**不得**把库外信息冒充已核验、**不得**制造"信息到此为止"的假象。
- 非医疗建议；涉及个人执行，一律指向持证医生 / 注册营养师。
